# GPS 기록장 (Android)

## 주요 기능
- 기록 간격 설정: 1분 이상, 분 단위
- 기록 시작/중지 및 상단 진행 알림
- 화면이 꺼지거나 다른 앱을 사용해도 포그라운드 서비스로 위치 기록
- 저장 항목: 기록시각, 위도, 경도, 정확도, 고도, 속도, 위치 제공자
- 휴대폰 내부 SQLite에 저장하며 인터넷 전송 기능은 없음
- CSV 파일 내보내기 및 전체 기록 삭제

## APK 자동 빌드 (GitHub)
이 프로젝트는 GitHub Actions가 APK를 자동으로 빌드하도록 설정되어 있습니다.

1. 압축을 풀어 `GPSLoggerAndroid` 폴더 안의 파일과 폴더를 확인합니다.
2. GitHub에서 새 저장소를 만들고 저장소 이름을 `GPSLoggerAndroid`로 지정합니다. 공개/비공개는 자유롭게 선택합니다.
3. 저장소의 `Add file` → `Upload files`에서 이 프로젝트의 **내용물 전체**를 저장소 최상위에 올리고 `Commit changes`를 누릅니다. `.github/workflows/build-apk.yml` 경로도 함께 올라가야 합니다.
4. 저장소의 `Actions` 탭에서 `Build GPS Logger APK` 작업이 실행되어 완료될 때까지 기다립니다.
5. 성공한 작업을 열어 아래쪽 `Artifacts`의 `GPSLogger-Android-APK`를 누르면 ZIP 파일이 내려받아집니다.
6. 내려받은 ZIP을 압축 해제하면 `app-debug.apk`가 있습니다. 휴대폰에서 APK를 열고 설치를 진행합니다. 필요한 경우 브라우저/파일 앱에 '알 수 없는 앱 설치 허용'을 켭니다.

## 최초 실행 및 사용
1. 앱을 열고 위치 권한을 허용합니다. 정확한 좌표 기록을 위해 '정확한 위치'를 허용해야 합니다.
2. 기록 간격을 분 단위로 입력합니다. 최소값은 1입니다.
3. `기록 시작`을 누릅니다. 상단 알림의 `GPS 기록장`이 표시되면 서비스가 실행 중입니다.
4. 중지할 때는 앱의 `기록 중지` 또는 상단 알림의 `기록 중지`를 누릅니다.
5. `CSV 파일로 내보내기`를 눌러 저장 위치를 선택합니다.

## 배터리/위치 설정 참고
- 휴대폰의 위치 기능과 GPS를 켜 두어야 합니다.
- 삼성 등 일부 기기에서는 설정 → 애플리케이션 → GPS 기록장 → 배터리에서 제한을 완화하면 백그라운드 기록 안정성에 도움이 됩니다.
- Android와 기기 제조사의 전원 관리 정책, 실내·지하 GPS 수신 상태에 따라 실제 수집 시점이 설정 간격보다 늦어지거나 위치가 저장되지 않을 수 있습니다. 1분은 요청 간격이며 모든 환경에서 정확히 60초마다 기록됨을 보장하지 않습니다.
- 앱을 강제 종료하거나 설정에서 강제 중지하면 기록이 멈춥니다.

## 개발 정보
- 패키지: `kr.go.pyeongtaek.gpslogger`
- 최소 Android: 8.0 (API 26)
- 빌드: Android Gradle Plugin 8.7.3 / Gradle 8.9 / Kotlin 2.0.21
- Debug APK는 테스트용 디버그 서명으로 빌드됩니다.
